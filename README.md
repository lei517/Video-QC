# Video-QC
简易视频自检小工具

**一、工具简介**

VideoQC 是一个全自动视频质量检测工具（机审），目前仅支持**信号级检测**，会扫描视频并输出问题报告：

| 问题类型 | 检测内容 |
|---------|---------|
| 黑帧 | 画面全黑或近全黑的帧（含单帧黑闪） |
| 跳帧 | 画面冻结、时间戳断裂丢帧、重复帧卡顿、突变坏帧 |
| 黑边 | 画面不铺满（含首/末帧海报四周的暗边） |
| 爆音 | 音频削波（破音）与响度突刺 |

**二、环境要求**

- Windows 10/11（64 位）
- **无需安装任何其他软件**（Python、FFmpeg 均已内置）

**三、使用方法（图形界面）**

1. 解压后得到 `VideoQC.exe` 和 `config.yaml`（两个文件放在同一文件夹）；
2. **双击 `VideoQC.exe`** 打开工具窗口；
3. 点击「选视频」选择单个视频文件，或点击「选文件夹」选择整个视频文件夹；
4. 点击「开始检测」，日志区会实时显示检测进度；
5. 检测完成后会**自动打开报告文件夹**，也可点击「打开报告文件夹」随时查看。

> - 想换报告保存位置：修改窗口中「报告目录」一栏。
> - 也可以把视频直接**拖到 exe 图标上**，窗口打开后会自动开始检测。
> - 首次运行需解压内置组件，启动稍慢（约 10 秒），属正常现象。

**四、报告在哪里看**

检测完成后，报告默认输出在 **exe 所在文件夹下的 `output` 目录**：

| 文件 | 用途 |
|------|------|
| `QC报告_日期_编号_视频名.xlsx` | Excel 版问题清单（集数 / 来源 / 问题类型 / 问题描述 / 图片）
| `QC报告_日期_编号_视频名.html` | 网页版报告，双击用浏览器打开，**内嵌问题截图/波形图，肉眼复核** |
| `output/screenshots/` | 所有问题时间点的截图文件 |

**五、常见问题**

**Q1：双击 exe 没反应或窗口打不开？**
确认 `config.yaml` 和 exe 在同一文件夹；若仍不行，右键 exe → 属性 → 勾选「解除锁定」，并等待 10 秒。

**Q2：杀毒软件报警？**
打包类 exe 偶被误报，请加入信任/白名单即可，工具本身只读视频、不修改任何数据。

**Q3：如何临时关闭某项检测？**
用记事本打开 `config.yaml`，把对应检测器的 `true` 改为 `false`（阈值也可调，文件内有中文注释）。

**Q4：报告里「集数」为 0？**
集数从文件名解析（如 `EP03_xxx.mp4` → 3），文件名不含 EP+数字时显示 0，不影响检测。

**Q5：检测一个视频要多久？**
约为视频时长的 1～2 倍（逐帧解码所致），属正常速度，检测中请勿关闭窗口。

**Q6：高级用法（命令行/批量）**
也支持命令行：`VideoQC.exe 视频路径 -o D:\输出目录`，可用于脚本批量调度。
