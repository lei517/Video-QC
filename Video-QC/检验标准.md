# 视频 QC 机审工具 · 检验标准（信号级 v1.3）

> 本文档为工具当前实际执行的判定标准，与 `config.yaml` 阈值一一对应。
> 每项包含：判定规则、排除规则（防误报）、输出形式。更新时间：2026-08-28

---

## 一、黑帧

**定义**：画面接近全黑的帧，含切镜处的单帧黑闪。

**判定规则**（逐帧全帧率解码，不放过单帧）：
满足以下任一分支即判定为黑帧：
1. 整帧平均亮度 ≤ 8 **且** 99% 分位亮度 ≤ 32（允许零星亮点/编码噪点，抓切镜黑闪帧）；
2. 整帧平均亮度 ≤ 20 **且** 整帧最高亮度 ≤ 48（整帧均匀近黑）。

连续黑帧时长 ≥ 0.03 秒（约 1 帧）即上报，输出起止时间。

**排除规则**：夜景、暗场景不判黑帧——暗画面存在光源/招牌等亮点（最高亮度 > 48 或 p99 > 32），两个分支均不满足。

## 二、跳帧（四通道）

### 2.1 画面冻结
**定义**：画面内容静止不变（含黑帧除外的静止画面）。

**判定规则**：相邻帧内容差异低于噪声容限（-60dB）且持续 ≥ 1.0 秒，判定为冻结，输出起止时间与持续时长。

**排除规则**：与黑帧时间段重叠 ≥ 50% 的冻结不上报（黑画面必然"静止"，避免与黑帧重复）。

### 2.2 时间戳断裂（丢帧）
**定义**：视频流帧时间戳不连续。

**判定规则**：相邻帧 PTS 间隔 > 标称帧间隔（中位数）× 2.0，判定为疑似丢帧，输出断点时间与实际间隔。

### 2.3 重复帧卡顿
**定义**：连续多帧数据完全相同（编码器卡帧、帧补偿性重复）。

**判定规则**：全分辨率逐帧比较，连续 ≥ 4 帧与前一帧平均差 ≤ 0.05（约 0.13 秒@30fps）判定为卡顿，输出起止时间与重复帧数。

**排除规则**：缓慢运动/静止画面不判——正常画面即使静止也存在编码噪点（全分辨率帧间差 ≥ 0.46），与真重复帧（≤ 0.01）有 10 倍以上区分度；与冻结、黑帧区段重叠的重复帧不重复上报。（注：判据必须在原始分辨率执行，缩略图会抹掉编码噪点导致误判。）

### 2.4 突变坏帧
**定义**：单帧内容异常（花屏帧、错乱帧、AI 生成 glitch 帧）。

**判定规则**：某帧与前后帧的平均差均 ≥ 35，且前后帧彼此相似（亮度差 < 17.5），判定为突变坏帧，输出帧时间点与差异值。

**排除规则**：黑帧不判（平均亮度 ≤ 8 的帧由黑帧通道负责）；场景切换不判——切镜边界帧只有单侧差异大，不满足"前后均差异大"。

## 三、黑边（画面不铺满）

**定义**：画面内容未铺满视频帧，边缘存在黑色/暗色条带。分 A、B 两型。

### 3.1 A 型：纯黑缝隙黑边（全片检测，每秒采样 1 帧）
**判定规则**，同时满足：
1. 边缘行/列中位亮度 < 24，连续暗带宽度 ≥ 画面尺寸的 0.5%；
2. **外缘平整度**：画面最外侧 8px 条带平均亮度 ≤ 4 且标准差 ≤ 2（内容未到达边缘）；
3. 中心区域（中央 50%）平均亮度 ≥ 48（排除黑场转场）；
4. 黑边持续 ≥ 1.0 秒，且区段内宽度波动 ≤ ±30% 的采样点占比 ≥ 60%（排除转场渐变）。

输出：方位（上/下/左/右）、宽度像素数与占比、起止时间。

**排除规则**：夜景、酒吧等暗场景——其暗部纹理必然延伸到画面最边缘（外缘条带标准差 > 2），第 2 条不满足；黑边带内存在字幕、水印、暗色渗漏内容**不影响**判定。

### 3.2 B 型：封面/海报帧暗边（仅检测首帧与末帧）
**定义**：海报/封面图未铺满，缝隙为近黑渐变（亮度 12-30，非纯黑）。

**判定规则**，同时满足：
1. 边缘暗带亮度 ≤ 30，宽度 ≥ 画面尺寸的 0.5% 且 ≤ 50%；
2. **锐利台阶**：暗带与内容交界处的亮度跳变 ≥ 80（海报为数码矩形直边，跳变实测 150-180；夜景渐变的跳变 ≈ 0）。

输出："起始帧/结尾帧画面未铺满（疑似海报/封面帧）"，方位与宽度。

## 四、爆音（双判据，重叠自动合并）

### 4.1 削波（波形压平）
**判定规则**：以 5ms 窗口分析 48kHz 波形，同时满足：
1. 窗口峰值 ≥ 0.90（满幅为 1.0）；
2. 窗口内 ≥ 20% 样本幅值达到窗口峰值的 95% 以上（"平头"特征，对有损编码电平衰减稳健）；
3. 连续削波 ≥ 10ms（间隔 < 0.2 秒的区段合并）。

输出：起止时间与峰值电平（dBFS），配波形截图。

### 4.2 响度突刺（突然炸响）
**判定规则**：以 0.1 秒窗口计算响度，同时满足：
1. 窗口响度高于**前后 ±5 秒邻域中位数**（局部基线）10 dB 以上；
2. 窗口响度 > -25 dB（避免安静段落误报）；
3. 持续时长 ≤ 2.0 秒（超过则为音乐/场景音，属响度问题而非爆音）。

输出：起止时间与超出背景的 dB 值，配波形截图。

**合并规则**：削波与突刺时间段重叠 ≥ 30% 时合并为一条（削波为主判据，突刺响度并入描述）。

## 五、报告输出标准

| 列 | 标准 |
|----|------|
| 集数 | 从文件名解析（`EP数字`，如 EP02_xxx.mp4 → 2），无法解析为 0 |
| 来源 | 固定"机审" |
| 问题类型 | 黑帧 / 跳帧 / 黑边 / 爆音 |
| 问题描述 | `HH:MM:SS,mmm-HH:MM:SS,mmm + 描述`，单帧问题起止相同 |
| 图片 | 画面类问题配问题帧截图（精确取帧，即判定所用帧）；爆音配波形图 |

同时输出 Excel（对齐机审样表）与 HTML（截图内嵌）两份报告。

**报告命名规则**：`QC报告_日期(YYYYMMDD)_编号_视频名`，编号为当日递增序号（001 起）；单视频检测用视频文件名，批量文件夹检测用文件夹名。示例：传入 `video.mp4` → `QC报告_20260828_001_video.xlsx` / `.html`。

## 六、已知边界（当前版本的取舍）

1. 黑边带内烧入大面积字幕/亮块的极端情况可能漏检（你方片子字幕在画面内容区内，暂不受影响）；
2. 渐隐转场在完全黑的一瞬（约 0.03-0.13 秒）会被报为黑帧，属真实黑帧，如不需要可将黑帧 `min_duration` 调至 0.5；
3. 爆音突刺判据可能命中剧情音效（如突然拔高的配乐），该类条目建议人工复听确认。
